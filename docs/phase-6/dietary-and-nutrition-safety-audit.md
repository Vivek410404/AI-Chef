**Milestone:** Phase 6.0 Controlled Household Pilot Readiness

## 1. Executive Summary

Dietary integrity is a safety-critical foundation of RasoiIQ. The platform enforces multi-layered deterministic validation across all recipe selection and generation workflows. Every recipe—whether sourced from the catalog or generated by AI—is strictly validated against verified ingredient metadata before reaching household screens.

## 3. Dietary Compliance Verification

| Rule / Constraint | Validation Mechanism | Test Evidence | Status |
| :--- | :--- | :--- | :--- |
| **Vegetarian Exclusion** | Rejects recipes containing meat, poultry, fish, seafood, and eggs. | `recipe-punjabi-chicken-curry`, `recipe-bengali-macher-jhol`, and `recipe-egg-curry` strictly excluded from Vegetarian pool. | PASS |
| **Eggetarian Mode** | Allows egg-based dishes while strictly excluding meat, poultry, and fish. | `recipe-egg-curry` permitted; chicken and fish dishes excluded. | PASS |
| **Vegan Mode** | Excludes meat, eggs, and all dairy products (milk, paneer, curd, ghee, butter). | Paneer and dairy dishes strictly excluded from Vegan eligible pool. | PASS |
| **Jain Restrictions** | Strictly excludes all root vegetables (potatoes, purple yam, radish, carrots), onion, garlic, and non-veg. | Zero Jain-incompatible recipes allowed in Jain mode. | PASS |
| **Unknown Ingredient Rule** | Unknown or unverified ingredient metadata must never silently default to safe. | `isIngredientMetadataVerified()` returns false for unverified ingredient objects. | PASS |
| **Multi-Member Resolution** | Multi-member households calculate the most restrictive common denominator for shared meals. | Mixed household (Jain + Eggetarian + Vegetarian) resolves shared diet to `JAIN`. | PASS |
| **AI Recipe Validation** | AI-generated meal suggestions must pass deterministic server-side validator before acceptance. | Validated via `AIPlanResponseSchema` and `filterEligibleRecipes()`. | PASS |

## 4. Allergen Safety Policy & Disclaimers

### Allergen Keyword & Category Mapping
Allergens are stored and checked independently from dietary preferences:
- `peanuts` / `peanut` / `groundnut`
- `tree nuts` (almonds, cashews, walnuts, pistachios)
- `dairy` / `lactose`
- `gluten` / `wheat`
- `mustard`
- `sesame`
- `fish` / `seafood`
- `eggs`

> [!CAUTION]
> **MANDATORY PILOT ALLERGEN DISCLAIMER:**  
> RasoiIQ provides automated filtering based on catalog ingredient declarations. However, RasoiIQ **does NOT guarantee allergen-free food**. Household members with severe food allergies must independently inspect commercial packaging ingredient labels and take precautions against domestic kitchen cross-contact.

## 5. Nutrition Calculation Engine & Methodology

### Nutritional Reference Standard
- Primary reference: **Indian Food Composition Tables (IFCT 2017)** published by the ICMR - National Institute of Nutrition (NIN).
- Secondary reference: **USDA FoodData Central** for standard dairy and international commodities.

### Gram Weight Normalization for Indian Culinary Units
To ensure accuracy, traditional non-gram Indian kitchen units are normalized using verified standard factors:
- `1 tbsp` = 15g
- `1 tsp` = 5g
- `1 cup` = 200g (dry/liquid standard Indian tea cup)
- `1 bunch` (coriander) = 25g, `1 bunch` (curry leaves) = 10g
- `1 piece` (egg = 50g, lemon = 40g, potato = 80g, onion = 90g, tomato = 70g)

### Transparency & Medical Disclaimer
All nutritional outputs (Calories, Protein, Carbohydrates, Total Fat, Fiber, Sugar, Sodium) are displayed alongside the following mandatory notice:
> *"Nutritional information is an automated estimate calculated from raw ingredient composition data (IFCT 2017 / USDA). Cooking methods, oil absorption, and brand variations may affect actual nutritional values. This is not medical or dietary therapy advice."*
